### 1. Corrección del Flujo de Estados de Dietas

**Problema identificado:**
- El método `SolicitarDietaAsync` cambiaba el estado directamente a `Confirmada`
- Esto rompía las validaciones en `ConfirmarDietaAsync`, `ConfirmarDietasMasivasAsync` y `CancelarDietaAsync`

**Solución implementada:**

#### a) Actualizado `EstadoDieta` enum
```csharp
public enum EstadoDieta
{
	Pendiente = 1,
	Guardado = 2,
	Solicitada = 3,      // ✅ NUEVO
	Confirmada = 4,      // Cambiado de 3 a 4
	EnPreparacion = 5,
	// ... resto de estados renumerados
}
```

#### b) Corregido `SolicitarDietaAsync`
- Ahora transiciona a estado `Solicitada` (no `Confirmada`)
- Elimina la lógica del flag `Guardar` (ya no usado)

#### c) Refactorizado `ConfirmarDietaAsync`
**Antes:**
```csharp
Task<bool> ConfirmarDietaAsync(Guid filaDietaId, string usuario, ...)
```

**Después:**
```csharp
Task<FilaDietaDto> ConfirmarDietaAsync(Guid filaDietaId, SolicitudDietaDto confirmacion, string usuario, ...)
```

**Mejoras:**
- ✅ Valida que la dieta esté en estado `Solicitada`
- ✅ Permite ajustes opcionales (tipoDietaId, consistencia, observaciones)
- ✅ Retorna el DTO completo (antes retornaba bool)
- ✅ Lanza excepciones descriptivas

#### d) Actualizado `ConfirmarDietasMasivasAsync`
- ✅ Valida que cada dieta esté en estado `Solicitada`
- ✅ Salta dietas que no cumplan validación (log de advertencia)
- ✅ Retorna count de confirmadas vs intentadas

#### e) Corregido `CancelarDietaAsync`
- ✅ Valida que el estado sea `Solicitada` O `Confirmada`
- ✅ Lanza excepción si el estado es inválido

#### f) Actualizado Controller
```csharp
[HttpPost("dietas/{filaDietaId}/confirmar")]
public async Task<IActionResult> ConfirmarDieta(
	Guid filaDietaId,
	[FromBody] SolicitudDietaDto? confirmacion,  // Body opcional
	CancellationToken cancellationToken)
{
	confirmacion ??= new SolicitudDietaDto();  // Default si no viene
	var resultado = await _dietasService.ConfirmarDietaAsync(filaDietaId, confirmacion, usuario, cancellationToken);
	return Ok(resultado);  // Retorna DTO completo
}
```

#### g) Actualizada Interface
```csharp
public interface IDietasService
{
	Task<FilaDietaDto> ConfirmarDietaAsync(
		Guid filaDietaId, 
		SolicitudDietaDto confirmacion, 
		string usuario, 
		CancellationToken cancellationToken = default);
}
```

## 🔄 Flujo de Estados Validado

```
┌──────────┐
│Pendiente │ ◀── Censo crea filas aquí
└─────┬────┘
	  │ ▼ Solicitar dieta
┌────────────┐
│ Solicitada │ ◀── Nutrición define tipo/consistencia
└─────┬──────┘
	  │ ▼ Confirmar dieta
┌────────────┐
│ Confirmada │ ◀── Enviada a cocina
└─────┬──────┘
	  │
	  ├─→ EnPreparacion → ListaEnvio → EnRuta → Entregada → Consumida
	  │
	  └─→ Cancelada (desde Solicitada o Confirmada)
```

**Transiciones validadas:**
- ✅ Pendiente → Solicitada
- ✅ Solicitada → Confirmada
- ✅ Solicitada → Cancelada
- ✅ Confirmada → Cancelada
- ❌ Pendiente → Confirmada (bloqueado)
- ❌ Entregada → Cancelada (bloqueado)
